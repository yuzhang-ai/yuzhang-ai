AI 产品经理：一边把设计和动效的判断写成 coding agent 能执行的 skill，一边每天出一期 AI 日报。作品和更多内容在 [oaioil.cn](https://oaioil.cn/)。

## English

AI product manager in Beijing. Designer before, product now, with AI in the loop: I write the judgment calls of design and motion down as skills that coding agents can follow, and I publish an AI daily brief every morning. Portfolio and more at [oaioil.cn](https://oaioil.cn/).

> Where to start: for how an agent is taught to produce pages that look designed, read [codex-ui-designer-kit](https://github.com/yuzhang-ai/codex-ui-designer-kit) and [web-animation-skill](https://github.com/yuzhang-ai/web-animation-skill); for what that method produces, open [MeloVista](https://melovista.vercel.app/) and the [AI Daily Brief](https://yuzhang-ai.github.io/ai-daily/en/).

| Project | What it does | Open |
|---|---|---|

Design workflow, worked cases and an acceptance guide | [README](https://github.com/yuzhang-ai/codex-ui-designer-kit#readme) |
